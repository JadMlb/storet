# Storet

[Voir la version en Français](README.fr.md)

## Description
Storet is a simple stock manager web app to manage local stock. It is a play on the words "store it".

The main purpose of this project is to showcase my ability to build a **Fullstack** web application by applying the following concepts:
- **Test-Driven Development (TDD)**
- **SOLID**
- **Clean Code**
- **N-Tier Application Development**

## Tech stack
- `Angular 21`
- `.NET 10`

## Key Features
- Manage local stock
- Manage stock transactions (entries & usages)
- Track usage
