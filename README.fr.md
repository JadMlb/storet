# Storet

[Check the English version](README.md)

## Description
Storet est une simple application web de gestionnaire de stock local. Son nom est un jeu de mots sur la phrase anglaise "store it".

Le but principal de ce projet est de démontrer ma capacité à mettre en place une application web **Fullstack** tout en applicant les concepts suivants :
- **Développement piloté par les tests / Test-Driven Development (TDD)**
- **SOLID**
- **Clean Code**
- **Développement d'applications N-Tier**

## Stack Technique
- `Angular 21`
- `.NET 10`

## Fonctionnalités clés
- Gestion du stock local
- Gestion des transactions de stock (entrées & usages)
- Suivi d'usage
